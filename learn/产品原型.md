# 产品原型

## 层级

产品和页面插槽不是同一层：产品决定用户进入哪一摊；页面插槽只扩展某个产品内部。

```text
Host
└─ web 服务
   ├─ routes 登记处 B
   ├─ products 登记处 B
   │  ├─ chat 产品
   │  │  └─ 页面插槽：message.actions、dock、composer.actions、sidepanel
   │  ├─ movie 产品
   │  └─ werewolf 产品
   └─ 公共页面插槽：settings.section
```

插件是启动代码；产品是插件填入 `products` 的一个用户入口。bash 插件不登记产品；电影插件登记产品和路由，但不碰对话页插槽。

### 产品登记

```text
Product
├─ ID / 名称 / 图标 / 顺序
├─ BasePath
└─ 左侧产品导航
```

产品不登记一张固定的 main 页面：`/movie`、`/movie/123` 等页面由产品插件分别登记路由，路由返回的片段整体替换 `main`。

### 页面插槽

页面插槽是 Web 内部的登记处 B，不各自在 Host 上占服务键。

| 形状 | 含义 | 当前例子 |
|---|---|---|
| `single` | 一个占用者，整体替换 | 当前产品导航 |
| `list` | 多个条目按顺序追加 | `message.actions`、`dock`、`composer.actions`、`settings.section` |
| `keyed` | 按类型名选择画法 | `sidepanel` 的 file / browser / editor / chat |
| `chain` | 按状态决定谁接管 | 未来多个插件接管输入区时再实现 |

审批现在由对话页根据运行状态把输入框切成审批框，不先实现通用 `chain`。

## 页面外壳

```text
Web
├─ 左侧栏
│  ├─ 产品入口：来自 products 登记处
│  └─ 产品导航：来自当前 Product
└─ main：随当前产品整体替换
```

| 当前产品 | 左侧产品导航 | main |
|---|---|---|
| 对话 | 项目、会话列表 | 对话页；可有右侧面板 |
| 电影 | 影片库、目录 | 电影页 |
| 狼人杀 | 房间列表 | 游戏棋盘 |
| 谁是卧底 | 房间列表 | 游戏棋盘 |

`sidepanel` 只属于对话页，不属于 Web 公共外壳。

### main 切换

`main` 是固定的 HTML 容器。用户点击产品入口后，HTMX 请求对应路由；插件返回 templ 页面片段，HTMX 整体替换 `main`。

```text
点击电影 → GET /movie → 电影插件返回页面 → 替换 main
```

切换时不刷新整个网页，并同步更新 URL；刷新或直接访问该 URL 仍能打开对应产品。左侧产品导航与 `main` 在同一次响应中一起切换。

## 设置

```text
设置
├─ 一级栏目：待设计
└─ 插件
   └─ 二级选择具体插件
```

已拍板：插件设置统一进入「插件」，再二级选择具体插件，避免插件过多撑爆左栏。其他一级栏目尚未确定。

## 对话页

### 顶部

```text
对话 | 轨迹
```

这是同一 Session 的两种固定视图，不是插件插槽。v1 删除 `header.actions`；以后真有第三种稳定视图再重新设计。

### 消息操作

```text
复制 | 分叉 | 插件登记的其他操作……
```

- 分叉：从当前消息创建新会话。
- 不提供点赞、点踩。
- 保留 `message.actions`，供插件登记自己的消息操作。

### Dock

`dock` 位于输入框上方，供 Todo、Goal、子任务等插件显示当前对话的持续状态。

```text
折叠：任务名称、进度、状态
展开：任务详情与操作
```

`dock` 是列表；每个插件条目独立展开或折叠。状态不写进聊天消息。

### 输入操作

`composer.actions` 位于输入框工具栏，供插件登记附件、图片、语音等输入按钮。

它只扩展本次输入的产生方式，不改变固定的发送、停止、模型和思考档位。

### 输入区接管

审批不是弹层。对话运行到等待审批时，同一输入区域从普通输入框切换为审批框；处理完再切回来。

```text
普通输入框 → 等待审批 → 审批框 → 完成 → 普通输入框
```

### 右侧面板

`sidepanel` 只属于对话页，是面板类型登记处，不用于展示工具详情。

```text
SidePanel（可关闭、可调宽度）
├─ Web 固定外壳：Tab 栏、+、关闭、宽度
├─ 面板类型登记处 B：file、browser、editor、chat
└─ 当前页面的活对象：已开 Tabs、当前 Tab、开关与宽度
```

Web 负责右栏、Tab、`+`、关闭和宽度；插件登记面板类型并提供内容。`+` 展示已登记类型，例如新对话、打开文件、浏览器、编辑器。

工具调用仍在消息工具卡片中渲染，但可以触发打开文件等面板：已有对应 Tab 就切换；没有才新开。Tab 是页面临时状态，不写进 Session；v1 刷新后不恢复，未来需要时再用浏览器本地存储恢复。

不额外设 `sidepanel.actions` 等小插槽：面板内部按钮由面板自己渲染。
