# Harness 交互原型

本机 React + Vite 页面，使用从 shadcn 官方 Registry 安装的组件源码、Stone 语义 Token、Tailwind、Lucide 和系统字体。不是正式 Client，不连接 WebSocket、模型或真实用户数据。

```sh
cd prototypes/web
npm ci
npm run dev -- --port 5174
```

打开 `http://127.0.0.1:5174`。`npm run build` 执行类型检查并生成 `dist/index.html` 与静态资源，须由 HTTP 服务提供，不直接双击源码 HTML。

## 推荐试玩路线

1. 展开“用时 24 秒” → 工具组 → 单个工具详情。
2. 新建会话并发送；运行中再发一句是 Steer，点停止可看收尾；正常演示约 24 秒完成并收起。
3. 输入草稿后切换会话或设置，再回来；草稿仍在。
4. 点击“模型 · 思考”，切换模型与档位；左边用量是可点的演示值。
5. 添加/粘贴图片，移除缩略图；文字模型禁止附图。原型插话暂只演示文字。
6. 设置 → 外观切换主题；Agent 可新建、修改、保存、删除，默认/被会话使用的 Agent 不可删除。
7. 打开右侧空工作区；宽屏可拖动分隔线，键盘左右键也可调宽；窄屏变覆盖层。
8. 右上“原型演示”切换空页、运行、完成、失败、停止、断线；断线 7 秒后模拟恢复，禁用发送且不重发。

项目选择只输入示例项目名，不读取目录。命令/技能菜单仅插入示例文本，不执行命令。模型名称、用量、工具输出、最终回答均为示例，不表示真实能力。

## 源码阅读

- `src/styles.css`：Stone 亮暗语义 Token、布局与滚动边界。
- `src/App.tsx`：项目、会话、输入、模拟运行与工作区。
- `src/work-process.tsx`：整轮 → 连续工具组 → 单个详情。
- `src/settings-page.tsx`：外观与 Agent 设置。
- `src/demo.ts`：示例数据与类型。
- `src/components/ui/`：shadcn Registry 组件，业务组合不在这里。

只有主题、辅助面板开关和宽度写入带 `harness-prototype:` 前缀的本机存储。会话、草稿、图片与 Agent 更改仅在页面内存，刷新恢复示例。支持 WebMCP 的浏览器可调用同一演示状态动作；不支持时不影响界面。
