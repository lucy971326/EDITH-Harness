# UI 重构：四步实施计划

## 总结

重构只改变 Web 的视觉与 Chat 投影；不改 Session、Runner、SSE 协议或插件边界。

```text
1. 视觉地基 + 截图拍板
2. 全 Web 外壳与填充物迁移
3. Chat 工作流重构
4. 主题与状态验收
```

## 1. 视觉地基 + 截图拍板

- 重写 `surface/web` Token：亮/暗主题、系统字体、固定字号、4px 间距、统一圆角、边框层级、状态色、浮层阴影。
- 采用“细边框为主”：工作区以平铺布局表达层级；仅菜单、下拉层使用轻阴影。
- 增加公共 `ui-*` 规则：文字、panel、card、按钮、图标按钮、输入框、下拉框、导航、提示、空状态。
- 新增 `surface/web/ui`：
  - 内置 Lucide SVG 子集；
  - `ui.Icon(ui.IconSettings)` 这类受控常量；
  - 当前所有正式 Emoji / 字符图标迁移至此；品牌 `H` 保留。
- 增加唯一的小型偏好脚本：
  - 保存 `harness.theme = system | light | dark` 到浏览器本地；
  - 在页面绘制前设置根节点 `data-theme`；
  - 不碰 Chat SSE、`paint()`、账本或服务端状态。
- 设置页固定增加 Web 自己的“外观”栏目，只提供主题选择；删除演示插件里无实际效果的主题字段，字号保持固定。
- 先迁移 Web 外壳与设置页，给你看亮/暗两套真实截图；你拍板后才进入大面积 Chat 迁移。

## 2. 全 Web 外壳与填充物迁移

- 迁移侧栏、产品导航、设置页、Composer、Dock、右侧面板及全部现有 demo 填充物。
- 模板只使用公共视觉规则；Tailwind 只保留布局、尺寸和少量局部排列。
- 禁止新增裸颜色、任意 `rounded-*`、私有 SVG、正式 Emoji 图标。
- 保持当前 HTMX 路由、设置局部刷新、Dock SSE HTML 替换、右侧面板行为不变。

## 3. Chat 工作流重构

- 保留现有 JSON reducer、`RunID / StepSeq / BlockSeq`、SSE 排序与历史恢复。
- 只重写 `chat.js` 的投影 HTML：

```text
用户消息
  ↓
工作过程 ›                  默认收起
  ├─ 中间说明 / 推理
  └─ 已调用 N 个工具 ›      二级收起
       └─ 读取 AGENTS.md
            └─ 工具名、参数、结果、错误
  ↓
最终回答                    默认直接显示
```

- 运行中只显示一行安静状态，例如：

```text
正在工作 · 正在读取 AGENTS.md ›
```

- 完成、失败、停止、等待确认共用紧凑状态行；失败更醒目，但不做巨型红色卡片。
- 最后一条正文作为最终回答；工具前的临时说明、推理和工具事件收进工作过程。
- 过程与工具二级展开使用原生 `<details>`。
- 在现有 `chat.js` 增加极小临时展开状态：SSE 重画后仍保持用户已展开的项目；刷新页面后恢复默认收起。
- 历史账本已有工具名、参数、结果与失败事实；不新增字段、不迁移数据。

## 4. 验收与收尾

- 亮色、暗色、跟随系统均检查：
  - Chat 空态、运行中、完成、工具失败；
  - 设置页、Dock、右侧面板、Composer；
  - 宽桌面与窄桌面窗口，窄时优先保留主内容并关闭右侧面板。
- 检查键盘焦点、原生控件、图标可访问标签、对比度、减少动态效果。
- 只做必要验证：Templ 生成、样式构建、相关 Go/JS 测试与真实截图检查；不为重构重复铺大量测试。
- 将已拍板规则回写 [UI重构.md](/Users/lucy/Documents/Projects/Harness/docs/plan/UI重构.md)，完成后同步 `STATUS.md`。
