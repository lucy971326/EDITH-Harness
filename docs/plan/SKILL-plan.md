# Skill 设置页

## 目标与页面

先完成 Skill 的查看和个人管理，再推进 Agent、Hook、Command 扩展。沿用设置页的双栏布局；窄屏改为上下排列。

```text
Skills                                  + 新建 Skill
┌─ Skill 列表 ───────┬─ 概况 ───────────────────────┐
│ 搜索               │ 名称、说明、来源、状态         │
│ 个人               │ SKILL.md 正文预览             │
│ 项目名 · 只读       │ 文件位置、附属资源             │
│ .agents · 只读     │ 个人 Skill：[开关] [编辑] [删除]│
│ 系统 · 只读        │                              │
└────────────────────┴──────────────────────────────┘
```

左侧列出各来源，包括被同名 Skill 覆盖、配置有误的条目；名称完整显示，项目组显示项目名。右侧默认是概况，正文默认收起，点击可展开或收起全文；不展开表单，不堆说明文字。Skill 统一使用现有 `BookOpenCheck` 图标和公共 Token。

## 交互与数据

- **管理范围：**仅 `~/.harness/skills` 中的 Skill 可新建、编辑、删除和开关。项目、`.agents`、内置 Skill 可查看正文与复制文件位置，文件内容和开关均只读；没有选中项目时隐藏项目组。
- **新建与编辑：**新建时提供带 frontmatter 的 `SKILL.md` 模板；编辑时修改完整源码，保留自定义字段。已有 Skill 的名称须与目录名一致，不在编辑时重命名。编辑区沿用「保存／放弃／继续编辑」草稿保护，保存时检查文件版本；冲突保留草稿并提示重新读取。
- **开关：**点击即保存禁用状态，不移动或改写 Skill 文件。关闭后立即刷新当前聊天的候选列表；新的 Run 不再获得该 Skill。已开始的 Run 不因开关而停止。删除需确认，并明确提示会删除整个个人 Skill 文件夹及附属资源。
- **后端作为来源：**新增设置页读取、正文读取、保存、开关、删除接口，并同步 Go／TS 契约。设置页扫描与运行时发现共用来源顺序；设置页遇到单个损坏文件仍能打开并展示错误，个人 Skill 可在源码编辑区修复。保留现有跨 Provider 同名冲突规则，不暗中改变运行结果。

## 验证与约定

覆盖来源与覆盖状态、开关持久化及重启、新 Run 与聊天候选同步、无效文件修复、保存冲突、删除附属资源和只读来源拒绝写入。完成代码后统一运行一次 `make agent-check`；亮暗主题和窄屏由你用 `make run` 截图验收。

首版不导入本地文件夹，也不安装 Git 或市场 Skill。编辑、删除文件可能影响尚未读取该文件的运行中任务；开关本身只影响后续 Run。
