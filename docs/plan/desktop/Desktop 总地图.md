# Desktop 总地图

面向 Windows、macOS；Linux 保留 Web。个人使用版接受系统风险提示，先支持手动下载安装。

```text
EDITH Desktop
├─ [x] 基础体验    单实例、窗口恢复、托盘驻留、退出保护
├─ [x] 界面与通知  Windows 自绘标题栏、通用设置、后台通知
├─ [x] 产品身份    EDITH · 0.1.0 · 品牌图标
├─ [x] 构建与打包  Windows EXE + NSIS；macOS APP + DMG
├─ [ ] 专项验收    窗口/通知、Mac 覆盖升级与数据保留、WebView2 缺失环境
├─ [ ] 版本发布    上传两平台安装包、校验值、简短更新说明
└─ [ ] 检查更新    设置页发现新版 → 下载页 → 手动安装
```

**已验证：**Windows 安装、重装、升级、降级拦截、运行中拦截和卸载；Mac 安装后的图标比例。构建入口及安装规则见 [构建说明](../../../build/README.md)。

**发布前：**完成上图专项验收，并运行 `make test`。分发签名、公证与应用内自动替换暂不纳入个人使用版。
