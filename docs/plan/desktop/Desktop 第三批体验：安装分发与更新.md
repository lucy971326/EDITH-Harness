# Desktop 第三批体验：安装分发与更新

个人自用、第三方分发，接受系统风险提示。先完成安装包和手动更新。

```text
Desktop 最后阶段
│
├─ [x] 构建可运行的 .exe / .app
│
├─ [x] 1. 固定版本号、应用名称和图标
│      0.1.0 · EDITH · 现有品牌图标
├─ [ ] 2. 制作分发包
│      Windows：安装程序
│      macOS：.app → DMG
├─ [ ] 3. 验证安装、升级、卸载
│      保留 ~/.harness 中的会话与设置
├─ [ ] 4. 发布版本
│      上传各平台文件、校验值和简短更新说明
├─ [ ] 5. 设置页提供「检查更新」
│      发现新版 → 打开下载页 → 手动安装
└─ [ ] 6. Windows／macOS 实机验收
       全新安装、旧版升级、数据保留、系统提示
```

签名、公证和应用内自动替换不作为本阶段验收项。若以后需要自动更新，再结合安装方式处理运行中任务、退出与失败恢复。

`0.1.0` 是首个个人使用版本；后续发布再递增版本号。Bundle ID 保持原值，避免改变现有系统身份。
