# Desktop 首批体验：已实现，待实机验收

## 已完成

- **单实例**：Wails 在 `backend.Open` 前取得实例身份；再次启动唤醒并聚焦已有窗口，启动期间收到的唤醒请求也会处理。Web 占用数据目录时仍显示启动错误窗口。
- **窗口恢复**：Desktop 在 `~/.harness/desktop/window.json` 保存普通位置、尺寸和最大化状态；防抖写入、退出刷新。坏文件使用默认居中布局，旧显示器不可用时移回当前工作区。
- **后台驻留**：Windows/macOS/Linux 关窗直接隐藏到托盘，空闲时也可从托盘找回窗口；托盘可显式退出。Linux 托盘图标不可见时，再次启动 Harness 唤回窗口。
- **退出保护**：主会话与子任务草稿、编辑器未保存文件、设置草稿会触发确认；保存中禁止退出。显式退出确认后停止活 Run，并等待后台收尾。前端未响应时使用原生确认退路。
- **边界**：Wails 与窗口偏好只在 Desktop 接入层；Runner 只提供运行状态查询，业务 RPC 未改变。

## 验证与待验收

`make agent-check` 与 `make desktop-build` 已通过。Windows/macOS/Linux 的窗口、托盘及退出确认仍需实机交互验收；本轮不做通知、安装包、签名、自动更新或草稿持久化。
