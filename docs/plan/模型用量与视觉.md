# 模型用量与视觉

先读 `AGENTS.md`、`STATUS.md`。本篇只排步骤，不写实现细节。

## 已定

- `models.json` 手写 `contextWindow`、`vision`；`Models()` 给界面，`Stream()` 用上。
- 用量球只在每次模型调用结束后更新：`InputTokens + CacheReadTokens`。用户输入不改球。刷新后空着。
- 图留在账本；不看图的模型只在发给 LLM 时换成文字占位。屏幕仍显示原图。

## 步骤

### 1. 模型清单

`models.json` 加上窗口和是否看图。`Models()` 带给 Chat。

### 2. 用量球

已完成。球画在 Chat 页面上，不填 composer 插槽。

### 3. 附图

当前模型 `vision` 决定上传按钮是否可用。Composer 能附图；用户气泡能看见图。发送时按当前模型决定发原图还是文字占位。

## 不做

压缩、独立图片存储、为用量新建服务。Command 框架、刷新后恢复用量球。
