# 内置编辑器与基础工具升级方向

目标：在右侧工作区提供代码浏览、小幅编辑、AI 修改审核与安全撤销。文件后端已完成，当前从内置编辑器继续。

## 原则

- 优先借鉴 `reference/codex` 已验证且适合的实现，按 Harness 现有架构适配，避免新增无必要的抽象。
- Tool 与编辑器 RPC 各有入口和规则，共享 `kernel/machine` 底层契约，由 `plugins/machine/local` 实现；文件调用与通知统一走现有 WebSocket / JSON-RPC。
- 编辑器保持克制：允许修改已有文件，不提供新建、删除、重命名；自动同步，不设手动刷新按钮。

## 阶段二：内置编辑器

接入 Monaco、浏览文件树、多文件标签页、未保存标记与关闭确认。支持高亮、查找、保存、少量快捷键和路径行号跳转；外部修改自动同步，有未保存内容时保留草稿并提示冲突。

## 阶段三：Tool 升级与 Diff

升级 read 分页读取与 bash 输出处理。记录 AI 文件修改，展示文件级 Diff 与增删行数；实现撤销前版本校验，避免覆盖后续修改。编辑器与聊天界面复用修改记录。
