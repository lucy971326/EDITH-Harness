# MCP 阶段

更新：2026-09-27。首版已实现，后续功能与专项验收见下方。

## 已完成

- 设置页独立「MCP」入口：双栏概况／编辑，核心字段在上，高级配置折叠。
- 全局 Server 添加、编辑、启停、删除及连接重试；项目配置只读，显示来源与覆盖关系。
- STDIO、Streamable HTTP；支持环境变量与 Header 配置，敏感值不回传，明确替换或清除。
- 配置文件版本校验，拒绝覆盖并发修改；损坏的全局配置可备份重建，项目配置由用户修复。
- 新 Run 使用新配置，旧 Run 保持原连接到结束；单个 Server 失败隔离，项目同名项不回退全局。
- 复用工具调用、项目信任与审批；设置读取不触发项目连接或信任审批。
- 已有自动测试覆盖 STDIO／HTTP、版本冲突、脱敏、损坏修复、项目覆盖及新旧 Run 连接；本轮实现已通过 `make agent-check`。

## 未完成

- OAuth 登录与授权。
- 插件安装系统，以及插件提供的 MCP 来源与版本管理。
- 项目配置在界面内编辑（首版明确只读，后续是否开放待定）。
- 单个 Server 独立重连：当前按钮重连全部全局 Server。

## 待验收

- MCP 页亮暗主题、窄屏、草稿切换与高级表单的完整交互。
- 真实 Server 的完整增删改、启停、失败恢复，以及运行中改配置的专项验收。

配置与运行规则见 [DATA_MODEL](../../DATA_MODEL.md)、[设计书](../设计书.md)；界面规范见 [WEB_UI](../../WEB_UI.md)。
