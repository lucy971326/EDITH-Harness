# Chat 输入候选

`/` 面板属于 Chat。Chat 持有 `composer.suggestions` 登记处，统一展示候选，但不统一各系统的业务。

```text
Skills → Agent 判断可用范围 → Skill 候选来源 ┐
MCP    → Agent 判断可用范围 → MCP 候选来源   ├→ composer.suggestions → Chat
Commands                  → Command 候选来源 ┘
```

- Skills、MCP、Commands 不直接依赖 Chat；外层候选来源插件负责连接并填登记处。
- `/` 和 `$` 都可展示 Skill；选择后在当前光标处插入 `$skill-name`，消息卡在原位置显示图标和名称。
- Command 列表不经过 Agent；执行时，UI 命令交给 Chat，模型命令交给 Runner。
- MCP Tool 仍是普通 Tool；候选只负责展示状态或入口。
- Runner、Loop、Session 不认识 `/`、`@`、`!`、`$`。
- 统一的是候选格式和面板，不是三套系统本身。
