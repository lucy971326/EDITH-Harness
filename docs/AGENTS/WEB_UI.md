# Client UI 约束

源码入口见 [UI README](../../clients/ui/README.md)，后台架构见[设计书](../设计书.md)。本篇保留交互和状态边界，具体数值以 styles.css 与组件实现为准。

## 组织与调用

```text
App                    页面装配、选择与会话草稿
├─ chat / settings     聊天与设置
├─ workspace           侧栏、混合标签与视图编排
├─ editor / terminal / review / subagent
├─ client              类型化 RPC、订阅、重连
└─ state               Snapshot + 事件 → 同一份投影
```

共用源码在 `clients/ui`；唯一入口 `clients/main.tsx` 选择 Web／Desktop，注入连接、外部网址和通知能力。平台实现分别位于 `clients/web`、`clients/desktop`，共用页面不检测 Wails、不计算 WebSocket 地址；两端构建同一份 `clients/dist`。

Windows／macOS Desktop 关窗时都直接隐藏到托盘，不丢失任务、终端或草稿；显式退出由平台桥询问共用 UI 的终端标签、主／子任务草稿、编辑器和设置未保存状态，确认会停止运行和丢弃草稿，保存中禁止退出。页面不持有 Wails 生命周期。Linux 只保留 Web。

React 管显示与局部交互，普通 TS 管连接和投影；只经手写类型化 Client 调用，不在组件拼 RPC。后台不传 HTML、React 组件或任意 SVG。不引入 Next.js、通用 Store 或无真实需求的 UI 插件框架。

## 导航与功能登记

- `workspace/navigation.tsx` 是应用功能的唯一登记入口：动作登记执行回调，页面登记 Hash 地址、图标与内容；导航和页面分发共用登记表。新增网站、远程、定时等功能时，导入真实页面后登记，不先放置未实现的入口。
- 聊天地址为 `#/`，设置为 `#/settings`；Hash 导航适用于 Web 与 Desktop。切页面不改变当前会话与后台 Run；长期编辑器、终端仍由原有工作区持有，辅助区只在聊天页展示。
- `settings/sections.tsx` 统一登记设置分类、图标和面板。分类切换保留面板及草稿；各面板只报告 `dirty / saving`，设置外壳统一处理离开确认，包括浏览器页面返回。保存中不允许离开。
- 登记是静态、显式的页面组合，不是动态插件容器；页面拥有自己的业务状态，外壳只管理导航与布局。

Agent 设置只维护名称、系统提示词和工具，不提供执行类型选项。审批界面与 Web 通知共用 RPCClient 的审批监听集合，各自注销，不覆盖彼此的回调。

## 投影、订阅与输入

- 后台拥有业务事实；Client 只保存投影、路由、折叠、主题、面板与草稿。主聊天、子任务与 Diff 共用订阅生命周期，不复制账本。
- 先安装 Snapshot，再应用同 epoch、快照边界之后的事件；Entry.ID 去重，完整 Entry 替换同 ID 草稿，迟到增量不能重建已落账消息。序号缺口或 epoch 改变重新订阅，不自行猜序。
- 切会话解除旧订阅，切设置保留订阅；迟到订阅响应也需解除，不能覆盖新选择。恢复完成前禁用发送与停止，失败不能当空历史。
- 后台连接状态放品牌行右侧，以静态指示灯和“在线／连接中／离线”显示；离线点击重连，详细原因放统一 Tooltip。收起侧栏时在主标题栏显示同一控件；不在聊天顶部或侧栏底部重复展示连接提示。
- 断线只恢复读取与订阅，不自动重发发送、审批或撤销。关闭窗口不停止后台 Run；未知通知可忽略，反向请求需明确回答不支持或交给实现方。
- 草稿按会话保存一份文字、图片、引用与编辑版本。确认只清已提交版本／附件，迟到确认不清新编辑；失败保留。等待确认禁止重复提交，Stop 仍可用。
- 忙时带 expectedRunID 插话，检查点落账才确认；换轮或停止返回冲突并保留文字，无下一轮队列。Stop 响应不等于已结束，等待后台终态。
- 会话选择存 sessionStorage；草稿在内存，刷新不承诺恢复。设置以后端保存结果为准，运行中禁改，不在每条 Delta 上拉取标题与设置。
- Enter 发送、Shift+Enter 换行，输入法选词不提交；向上阅读暂停自动滚动。图片发送前压缩并校验模型支持，后台再次校验。

## 消息与引用

- Snapshot 和事件共用 reducer。定位使用 SessionID → RunID → EntryID → BlockSeq；工具结果按 ToolCall.ID 回填，插话后输出按 afterSeq 定位。
- 工作过程运行中展开、成功后收起，失败／停止保留展开；普通增量不覆盖手动折叠。说明、思考、工具、协作消息按结构呈现，不解析正文猜阶段，不维护第二份展示事实。
- 最终回答须为成功 Run 最后的完整助手正文，无工具调用或 summary，且锚点覆盖最后输入；缺 Run 状态、incomplete 或临时说明不能冒充成功结果。工具缺结果显示缺失，不推断正在执行。
- Markdown 仅用于用户消息与最终回答，并清洗 HTML；工具、推理和参数按纯文本展示。完整最终回答才可分叉，失败保留原会话与草稿。
- 主聊天可添加文件／目录、编辑器选区、已完成助手回答选区；不自动读取文件。代码引用保存当前 Model 的未保存内容，助手引用保存纯文本范围、Entry ID 与可选评论，不跟随来源变化。选区评论支持多行，Enter 确认、Shift+Enter 换行；弹窗内部滚动保持打开。
- 引用只通过普通 send.text 落账，不新增后端 Block 或引用表。文件／目录／代码用 harness-context-v1；含助手选区用 v2，后接 JSON 转义数组与“（上下文引用结束）”。仅还原用户正文末尾完整合法段，未知／损坏段原样显示。精确编解码见 `chat/context-references.ts`。
- 引用可整块删除，允许只发引用；助手引用编号只统计助手选区，删除后重排。编号在确认添加后保留至删除或成功发送，失败保留。候选与异步路径搜索忽略过期响应。
- `/` 按命令、Skills 分组，`$` 仅显示 Skills；候选名称不显示引出符，名称与描述同行。命令直接执行，运行中隐藏命令。选中 Skill 后在光标处插入可整块删除的行内标签，底层草稿与发送正文仍用 `$name`；候选支持键盘、鼠标与 Escape，富文本输入保留中文输入法、纯文本粘贴、图片粘贴及发送快捷键。
- 用户消息仅将当前可用的完整 `$name` 渲染为 Skill 标签；代码、链接和未知名称保持原文，Skill 移除后历史显示原始文本。复制消息使用原始正文。Skill 的菜单、输入和历史统一用 `BookOpenCheck` 及公共颜色 Token。

## 辅助工作区与文件保护

公共壳只管理混合标签、激活、关闭与新增菜单；每个视图拥有工具栏和内部状态。后台业务不归标签页。
辅助工作区只在聊天页可见；进入设置时收起，设置页不显示其入口，返回聊天后可重新打开。

- 编辑器按工作区保留本页标签、Model 与草稿。workspace-tabs 编排标签和关闭确认；editor/use-files 管打开、保存、冲突与监听。
- 保存携带读取时哈希；只确认提交快照，保存中的新输入继续保留。监听重读等待在途保存，冲突重读不等待自身。关闭后重开同一路径忽略旧文件对象响应。
- 干净文件外部修改自动重载；本地已改保留草稿，让用户选择重载或受版本保护的覆盖。删除、读写失败不丢缓冲，关闭未保存／冲突标签需确认；卸载清理定时器和监听。
- 本地文件链接可打开并定位行列，网络链接新标签打开。文件编辑沿用后台大小与编码限制。
- Diff 属于 Session，切会话清理；只挂载当前文件 DiffEditor。撤销须无活 Run，携带 revision，磁盘变化或旧响应不能覆盖新内容。
- 终端归 Client 连接，隐藏或切标签继续运行，关闭标签终止，断线由后台清理；输出与进程不写浏览器存储或账本。
- 子任务标签以稳定 TaskID 定位，重复点击激活；关闭父标签不关闭后代，关闭视图不停止任务。每页独立订阅、共用本页 RPC 连接；空闲仅可改模型与档位，不改 Agent／工作区。

## 审批与设置

- 设置使用独立导航与内容区，隐藏聊天导航和工具栏；窄屏分类横排。「通用」内含外观与通知，外观即时生效；其余表单明确显示未保存状态和保存操作。分类切换保留草稿，离开设置前确认未保存修改，保存中禁止离开。
- 通知在 Web 与 Desktop 各自默认关闭并独立保存开关；仅用户开启时请求系统授权。失焦后只提醒新人工审批和 Run 成功／失败，取消、初次快照与重连不补发。设置页测试按钮只在已开启且获授权时可用，允许聚焦时发送，不改变开关或关联会话；成功反馈仅表示已交给浏览器或系统。通知文案不包含会话内容；点击先唤回，再经设置草稿保护定位会话，目标已删除时显示提示。Web 只在标签仍打开时提醒，Desktop 的 Wails 服务故障不影响 Run。
- 设置分类内部统一使用左侧对象／子项导航、右侧详情；窄屏将子导航移至详情上方。外观显示主题选择，Agent 选择具体 Agent，审批选择方式或目标，Hooks 选择全局或项目范围。切换 Agent 或 Hook 范围时，对未保存草稿提供保存、放弃与继续编辑。
- 设置详情统一使用图标、标题与右侧操作区；连接信息使用紧凑键值摘要，列表使用统一圆角和分隔线。命令与参数等核心字段优先展示，工具过滤、超时等放入默认折叠的高级设置；表单保存栏在正常文档流的内容末尾，不悬浮、不遮挡字段，删除操作置于保存栏之前。归档页左侧按完整项目路径筛选，右侧搜索与管理会话。
- Skills 设置按个人、当前项目名、`.agents`、系统分组；默认显示概况，正文和附属资源默认收起，可展开阅读全文。只有个人 Harness Skill 可编辑完整 SKILL.md、启停或删除；切换未保存草稿提供保存、放弃与继续编辑。列表保留损坏或被覆盖的条目，单个损坏文件不挡住设置页。
- 「模型与供应商」为单层设置分类，内部分供应商列表与详情。默认显示连接概况和模型列表，单独进入连接或模型表单；预设与手动创建共用表单，先保存供应商再添加模型。有模型时不允许更改供应商协议；切换未保存表单时明确提供保存、放弃与继续编辑。密钥只输入新值，读取仅显示是否已配置；空输入保留原密钥，显式清除才删除。保存冲突或失败时读取磁盘状态并保留表单草稿。删除模型或供应商直接执行，不弹确认框；删除供应商同时移除其模型，可用模型清空后仍能从设置重新添加。
- ChatGPT 订阅是模型供应商列表的内置连接，概况中显示登录、等待、失败与退出状态；授权网址由后台生成，Web 在新标签、Desktop 在系统浏览器打开。页面只接收状态，不接触授权码或令牌；登录完成后刷新可用模型。订阅连接使用固定地址，没有供应商编辑表单，模型可从预设添加。
- 待审批框替换主输入框，保留草稿；展示真实理由、操作与来源，所有会话请求依次处理。断线禁答，重连恢复快照，不自动重发决定。
- 思考档位编辑采用紧凑有序列表：每档只填写思考强度，新增或修改时同步生成名称，`off` 表示关闭；支持添加、移除和排序，不展示独立名称、模式和预算表单。未修改档位保留已有名称映射与协议参数；已有 Anthropic 预算保留，新建手动思考档位沿用 1024 token 默认预算。空值或重复强度不能保存。
- 项目 MCP 确认只显示脱敏的连接摘要并记住该版本，工具批准仅本次有效；明确宿主执行边界。设置页只读查看项目 MCP 时不连接或请求信任，读取接口只返回已配置状态，不返回环境变量展开后的命令、参数、URL 或 Header。权限模式由后台提供，不在前端硬编码；用户编辑器／终端不经 Agent 审批。
- HTTP MCP 只有在服务端报告需要登录／增加权限、已有本机凭据或授权任务留在页面中时才显示授权操作；普通已保存或已连接状态不展示登录入口。登录由设置页显式启动，等待授权、失败、取消与退出登录使用同一紧凑状态提示；授权服务不支持自动注册时，失败任务给出配置入口，不在页面顶端报原始协议错误。项目 Server 登录前再次确认该项目配置，弹窗列出将被信任和连接的所有已启用 Server，明确提示 STDIO 会在宿主执行命令；授权网址由后端任务给出，Web 打开新标签、Desktop 打开系统浏览器，用户完成本机回调。前端仅持有任务 ID、网址和脱敏状态，不接触 code、token 或客户端密钥。
- 智能审批设置以后端为准，新请求采用新设置，在途审核保持快照；转人工原因与 Agent 申请理由分开显示。密钥不回显到页面。
- Hooks 的点位列表和全局／项目 Hook 配置均从后端 `hooks/read` 获取，按 `flow` 分组。每个点位右侧的新增入口展开表单；新增或编辑提交成功即保存并收起，失败保留表单。排序和删除直接保存并使用版本检查；项目配置外部修改后重新信任，冲突须重载，失败提示不写账本。

## 视觉与验收

```text
暖中性工作台 + 克制信号橙 + 轻按键质感 + 安静阅读区
界面固定 Ginto + MiSans；内容 MiSans / HarmonyOS Sans
代码 JetBrains / Cascadia Mono / Maple Mono；中文统一 Noto Sans Mono CJK SC
紧凑导航与聊天；颜色、字号、间距统一走 Token
```

- 采用克制的器物风格：暖米色／深暖灰机身、轻分层导航与工作面板；聊天顶部栏先显示项目名，再显示稍大的会话标题，窄屏只显示标题；聊天正文保持平面。普通正文 14px、聊天阅读 15px、控件 13px、辅助文字 12px；编辑器和终端使用独立代码字号 Token。
- 空会话将介绍与输入框组成居中的开始区域，已有对话采用正文阅读区与底部输入框；输入框略宽于正文，过程信息弱于回答。未选项目时明确提供选择入口，选择成功后保留已输入的草稿。设置内容按双栏组织，主题预览展示在右侧详情区。
- `styles.css` 的语义 Token 是颜色、字号、间距、圆角、控件尺寸、阴影和过渡的唯一入口，经 `@theme inline` 映射到 Tailwind。间距以 4px 为基准；Web 与 Desktop 共用 `--workspace-gap`（8px）作为窗口外边距和面板间隙，侧栏、主区、辅助区及设置双栏共用 `workspace-panel` 边框、圆角和阴影；设置页的外层 `main` 只负责布局。窄屏贴边并将设置双栏合并；控件高度为 28／32／36px，控件／面板／浮层圆角为 8／14／16px，消息与输入框分别使用 12／18px 的语义 Token。
- Desktop 顶栏只在 Wails 显示，使用相同 Token；Windows 自绘窗口按钮并保留原生阴影和缩放，macOS 使用隐藏标题栏和原生交通灯。拖动区域与按钮不重叠；窗口按钮只调用平台能力，关闭继续走原有托盘生命周期。
- 器物质感通过现有语义 Token 与少量材质 Token 实现：`surface-base` 管机身底色，`key-* / signal-* / edge-highlight / shadow-*` 管公共控件材质，两主题同名覆盖。页面不复制配方，不增加第二套主题或系统平台判断。
- 信号橙用于主操作、运行标记和当前会话左侧的小灯；当前会话与设置导航选中态共用暖中性底色与 `--shadow-selected` 凹陷层次，右侧运行／审批／未读灯保持独立含义，不增加彩色侧边；正文、链接、Skill 标签分别使用可读的语义前景色，成功／警告／失败保留独立状态色。品牌 Logo 保持原样。字体全部随应用打包，不在导航和表单增加点阵英文标签。
- Composer 工具栏保持紧凑，上下文用量只显示小圆环，无有效数据时隐藏，百分比放在悬停／键盘聚焦提示中；不显示“用量／暂无”文字和独立重复栏。发送操作只显示图标，保留可访问名称与悬停提示；小标签与控件复用统一 Hover／焦点样式。ReAct 不展示步骤进度条；不为视觉添加假进度、计数或持续动画。改视觉不增加密度切换、声音或业务确认流程。
- Run 的文件改动只用现有回执卡片展示：左侧简洁图标，中间为真实文件数与增删行数，右侧审查入口；卡片整体可点击，复用公共轻按键材质与焦点样式，不另加成果卡或虚构完成进度。
- `components/ui` 统一基础控件与交互状态，公共样式放在 components 层，页面负责布局；修改同类外观时修改公共定义并移除旧覆盖，不在文件末尾叠加修补。拖动尺寸、内容宽度、树缩进和主题示意图保留各自用途。
- 亮／暗／系统主题共用 Token；Monaco、Diff 和终端从同一入口读取界面色、代码色及字号，主题切换仅更新现有实例的显示，字体加载后重新测量。外壳只用轻面板阴影，次要按键与可点击回执共用低对比底色、细边线、极浅明暗差和贴近底面的短阴影，悬停提亮、按下轻内凹；聊天输入区为一层凹陷托盘，文字区与工具栏共用连续纸面，以弱分隔线区分，不堆叠凸起卡片；普通列表、正文和图标操作保持平静。面板拖动不加醒目强调线。
- 左右面板展开／收起用 180ms 宽度过渡，保持编辑器与终端实例；关闭时不可聚焦，减少动态效果时立即切换，拖宽时禁用过渡。分隔线保留鼠标与键盘调宽；高频拖动按帧更新，松手才提交偏好。窄屏保障聊天空间，辅助区可覆盖显示。
- Composer 按自身宽度收缩模型与档位入口，权限／Agent／用量／发送停止始终可用。
- 模型入口只显示模型名与思考档位，省略供应商前缀，按内容宽度紧凑排列；完整模型标识保留在悬停提示中。
- Agent、权限与模型选择浮层共用面板宽度、圆角、标题说明和选项行样式；当前选项以暖中性选中背景与右侧勾选标记表示。
- 模型选择按供应商展开二级列表，思考档位在一级面板独立展示。滑块沿用 `~/.harness/models.json` 中 reasoning 的书写顺序，不按名称排序；拖动只预览，松手提交。切换模型优先保留兼容档位，否则使用配置中的第一档。旧会话所选模型被删除后禁发并要求重新选择。
- 使用静态受控图标，不用 Emoji 代替 UI 图标。普通右键菜单统一，Monaco 保留自身编辑菜单；支持键盘焦点与减少动态效果。
- 侧栏所有会话行固定预留左侧选中灯的位置，切换时标题不位移；会话名使用扣除右侧状态灯后的可用宽度，操作按钮只在悬停或键盘聚焦时占用行尾空间；触屏始终显示操作。输入栏保持紧凑，聚焦沿用输入栏阴影，不使用浮层阴影。Markdown 表格使用公共边框、圆角与间距，并在自身范围内横向滚动。
- 右键只在目标有实际操作时弹 Harness 菜单；侧栏与空白区域保留浏览器默认菜单。侧栏会话悬停或聚焦时显示归档、永久删除按钮，项目显示永久删除按钮。设置的「已归档会话」按项目分组并可搜索、查看、恢复和逐条删除；项目标题也可删除该项目。归档后清理当前选择与草稿，运行继续；归档会话查看时禁发，恢复后可续聊。永久删除先展示会话标题或完整项目路径与会话数，后台确认后再刷新列表。
- UI 由用户运行 make run 后截图验收；默认不新增 UI 自动化测试。验证重点是草稿保护、重连、取消、冲突与亮暗／窄屏交互。

- Agent 可用工具采用紧凑列表，工具统一使用 `Wrench`；每行名称与启用开关并列，完整说明按行展开，不默认铺开长篇工具描述。

### 图标语义

本地参考：`reference/lucide/REFERENCE.md`；官方说明与标签用于选图，业务含义以本节为准。参考目录不随仓库提交，图标/API 可用性以项目安装版本为准。

统一从 `icons.ts` 静态引入 Lucide 图标；按对象和操作选图，不按页面位置或装饰需要换图。相同对象在导航、列表、详情和共享选择器中保持一致；协议、作用域和状态用独立文字表达，不替换对象图标。

| 含义 | 固定图标 |
| --- | --- |
| 外观、主题设置 | `Palette` |
| 通用分类、系统通知 | `SlidersHorizontal`、`Bell` |
| 浅色、深色、跟随系统选项 | `Sun`、`Moon`、`Monitor` |
| Agent | `Bot` |
| 模型、思考 | `Brain` |
| LLM 供应商 | `Building2` |
| 审批 | `Shield` |
| 外部服务连接（如 Jev） | `Plug` |
| Hooks、回调点位 | `Webhook` |
| MCP Server（任何协议、作用域） | `Server` |
| 工具 | `Wrench` |
| Skill | `BookOpenCheck` |
| 全局作用域、项目、项目集合 | `Globe`、`Folder`、`Folders` |
| 归档、恢复 | `Archive`、`ArchiveRestore` |
| 编辑、添加、永久删除 | `Pencil`、`Plus`、`Trash2` |
| 移除表单条目、关闭 | `X` |
| 刷新／重试、搜索、复制 | `RefreshCw`、`Search`、`Copy` |
| 返回、展开、上移／下移 | `ArrowLeft`、`ChevronRight`、`ArrowUp`／`ArrowDown` |
| 设置入口、配置文件 | `Settings`、`FileText` |

`Settings` 不表示编辑，`Command` 不表示 Hook 或工具，`Bot` 不表示模型。图标尺寸、描边和颜色沿用公共 Token；图标按钮保留可访问名称与悬停提示，不为每段文字强行加图标。

## 字体与会话阅读状态

- 通用 → 外观只提供内容字体、代码字体选择；UI 固定 Ginto + MiSans。内容字体各自提供中英文，不随代码字体改变。三种代码字体均使用同一内置中文字体；用 CSS 字宽调整保证常用汉字占两格，不采用 Maple CN。
- 字体选择只属于当前客户端偏好，使用 `harness-web:fonts`；加载成功才更新 `--font-content / --font-code`，失败保留原选择。消息与输入正文使用内容字体，菜单／标签保持 UI 字体，代码块／Monaco／Diff／终端统一代码字体。编辑器与终端更新已有实例并重新测量。
- 侧栏状态优先级：等待审批（菱形）→ 运行中（空心圆）→ 未读完成结果（实心圆）；未读标题加重，Hover 显示统一 Tooltip，不闪烁。审批订阅由 App 持有，设置页切换不解除。
- 阅读位置归后端 `reading`，同一 appserver 的客户端共享；只在窗口可见且有焦点、当前会话实际滚到最新结果时确认所见 Run。后台验证已结束后推进位置，旧确认不能消掉新结果；保存失败保留未读。运行中不预先标已读。
- `harness/session/activity/subscribe` 先登记通知再取快照；`activity/changed` 仅失效通知，客户端串行刷新 `activity/list`，断线重新订阅。运行起止与成功已读确认触发刷新；慢连接沿用现有有界队列与断线恢复。
