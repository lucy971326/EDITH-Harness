# Web／Desktop 界面约束

源码入口见 [UI README](../../clients/ui/README.md)，后台边界见[设计书](../设计书.md)。这里保留影响数据正确性和产品行为的约定；具体色值、尺寸与组件外观以 `clients/ui/src/styles.css` 和公共组件为准。

## 状态与导航

`clients/main.tsx` 选择 Web 或 Desktop 平台并注入连接、外部网址、通知能力；共用 React 页面在 `clients/ui`，不检测 Wails、不拼 WebSocket 地址。Web 与 Desktop 构建同一份 `clients/dist`。React 管显示与临时交互，普通 TS 管连接与投影；组件通过手写类型化 Client 调 RPC，不保存第二份后台事实。

`workspace/navigation.tsx` 统一登记页面与动作，`settings/sections.tsx` 登记设置分类。聊天地址 `#/`，设置地址 `#/settings`；切页面不改变当前会话或活 Run。设置切分类保留草稿，离开前确认未保存修改，保存中禁止离开。Desktop 关窗隐藏到托盘；显式退出先检查终端、草稿、编辑器和设置的未保存状态，页面不直接管理 Wails 生命周期。

Snapshot 与事件进入同一个投影：先安装快照，再应用同 epoch 且晚于快照边界的事件；Entry.ID 去重，完整 Entry 替换草稿。序号缺口或 epoch 改变重新订阅，失败不能当空历史。切会话解除旧订阅，切设置保留订阅；断线只恢复读取与订阅，不重发发送、审批、撤销等副作用。连接状态在品牌行显示，离线可手动重连。

每会话保留一份内存草稿（文字、图片、引用、编辑版本）。发送确认只清已提交版本；失败、冲突或迟到确认不能清新编辑。忙时携 expectedRunID 插话，检查点落账才算成功；Stop 响应后仍等待后台终态。Enter 发送、Shift+Enter 换行，输入法选词不提交；图片先压缩并校验模型能力，后台再次校验。

## 聊天与会话

每轮只有一个“工作过程”折叠入口：运行中展开、成功后收起、失败或停止保留展开；折叠后只留入口行，最终回答与真实文件改动仍在外面。展开按时序显示中途正文、工具、插话和协作；正文保持正常文字色，操作行弱化。连续终端命令合并为可展开组，单条命令仍可再展开限高、内部滚动的参数与结果。无过程内容的成功回答下方不另显示“已完成”；没有耗时数据不伪造“用时”。

思考只在当前活草稿的末尾块生成时显示淡色短预览；开始输出正文、落账进入工具执行或 Run 结束后移除。后台仍保存完整思考及续接数据，已完成页面不显示思考块；只有加密续接、没有文字时不显示。最终回答须是成功 Run 最后的完整助手正文，覆盖最后输入；incomplete、工具调用或临时说明不能冒充最终回答。工具缺结果时显示缺失，不猜测正在执行。

用户消息和助手正文使用清洗后的 Markdown；工具参数与输出按纯文本展示。上下文引用只编码进用户 text：文件／目录记录路径，编辑器选区记录当时文本，助手选区记录完成回答范围与可选评论，不跟随来源变化；损坏或未知标记原样显示。选区评论 Enter 确认、Shift+Enter 换行；复制消息取原始正文。`/` 展示命令与 Skill，`$` 仅展示 Skill；命令由后台执行，不由组件模拟业务。

侧栏会话以背景和边框表示选中，不设选中灯；运行／待审批／未读是独立状态。悬停或聚焦显示归档与三点菜单，触屏仍可操作。菜单提供原位重命名、从末尾完整回答分叉、永久删除；改名 Enter 保存、Esc／失焦取消，失败保留输入。分叉沿用原标题、共用项目文件，运行中或末尾无完整回答时拒绝；删除先确认。归档不停止 Run，恢复后才能继续发送；手动已读只在当前会话实际看到完成结果时确认，旧确认不能抹掉新结果。

## 工作区与设置

辅助工作区可打开编辑器、Diff、终端和子任务；切设置时隐藏辅助区但不丢实例。编辑器保存携带预读哈希，只清已保存版本；外部修改与本地草稿冲突时保留草稿并让用户选择。关闭未保存／冲突标签需确认。Diff 按 Session／Run 定位，撤销须无活 Run 且携 revision；终端按 Client 连接拥有，断线清理，输出不写账本。子任务视图关闭不停止任务，父子共享项目文件。

“通用”包含外观与通知。Web／Desktop 通知各自默认关闭，用户开启后才申请系统权限；失焦后只提醒新人工审批和 Run 成功／失败，重连不补发，文案不含会话内容。待审批框保留聊天草稿，显示真实操作与来源；断线禁答。模型／MCP／Hooks 等设置以后台保存结果为准，失败保留表单草稿；密钥与令牌不回显。项目 MCP 只读查看不连接或请求信任，登录由用户显式发起；前端只持授权任务 ID、网址与脱敏状态。

## 视觉与验收

冷白阅读区、淡青玻璃导航侧栏、深色主操作、克制的状态色；暗色主题保留相同层次。玻璃只用于主导航和设置导航，正文、编辑器、终端与表单不透明。状态灯、读数和进度必须对应真实后台状态；不为 ReAct 虚构步骤总数。侧栏、正文与辅助区用细线分隔，不再套一层装饰性窗口面板。

颜色、字号、间距、圆角与动效走公共语义 Token；同类控件用公共组件，不在页面堆覆写样式。应用 UI 使用已打包的 MiSans，正文和代码字体按外观设置；图标含义一致，不用 Emoji 代替控件。普通悬停用 `--accent`，图标或截断内容需说明时用公共 Tooltip；完整可见文字不重复弹提示。状态不只靠颜色，键盘焦点可见，尊重减少动态效果。官网样式独立于应用。

视觉交互由用户运行 `make run` 截图验收；改代码时优先验证草稿、重连、取消、冲突及亮暗／窄屏。默认不新增 UI 布局或快照测试。
