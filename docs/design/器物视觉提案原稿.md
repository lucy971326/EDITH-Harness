**规则强度**（全文统一用法）：

| 标记 | 含义 |
| --- | --- |

## 1. 设计哲学：七条原则

### 1.1 状态即装饰（Status is the decoration）

这套风格的“装饰”不是额外画上去的，而是**真实状态本身**：指示灯亮不亮、刻度走到第几格、读数是多少。没有状态可表达的地方，就保持素净，**不要为了好看凭空加灯和刻度**。

- **必须**：指示灯、刻度、读数只能反映真实数据或真实状态，不能用动画假装任务在进行或已完成。
- 官网等没有实时状态的载体，可以用“静态快照”表达（例如产品截图里定格在 RUNNING 04/07），但**不要做成循环播放的假动画**。

### 1.2 只有可操作的东西才凸起

- **凸起（raised）= 可以按 / 可以拖 / 可以点**。
- **凹陷（inset）= 显示内容、承载输入、表示已选中或读数区域**。
- **平（flat）= 纯内容 / 文字底**。
- **必须**：不要给不可交互的元素做凸起；不要凸起叠凸起。

### 1.3 一个信号色，克制使用

只有一个强调色：**信号橙 `#ff5a1f`**。它的含义固定为“**活动 / 正在运行 / 主操作 / 当前选中**”。

- **应该**：橙色在任一屏幕上的面积不超过约 5%。
- **必须**：橙色不用作大面积背景、不用作正文文字色、不用作装饰渐变。

### 1.4 暖中性，不是纯灰

所有中性色都偏暖（略带黄棕），阴影也带暖色（`rgba(60,50,30,…)`），**不要用纯黑阴影或冷灰**。这是“像纸、像塑料、像铝壳”的关键。

### 1.5 仪器感，不是拟物

参考的是 Braun / Dieter Rams 式的克制，以及 Teenage Engineering 式的信号色与点阵读数——**只借“质感与秩序”，不做皮革、金属拉丝、螺丝钉、旋钮堆叠**。

- 立体感只靠**阴影和一条顶部高光**完成，不用纹理贴图。
- 每个立体元素都必须“有功能理由”。

### 1.6 标注文化（Labeled everything）

仪器面板上一切都有小标签。用**等宽大写小字 + 宽字距**给区域命名（例如 `SESSION`、`MODEL`、`OUTPUT`），像丝印在面板上的字。这是层级与秩序感的主要来源之一。

### 1.7 安静、耐看、能长时间使用

- 长时间阅读区域（聊天、文档、代码）**必须**平静：无持续动画、无发光闪烁、对比度充足。
- 视觉个性集中在“边框区域”（仪表条、标签、按钮、面板边缘），**内容区保持克制**。

## 2. 关键词与反关键词

**是**：工业设计 · 仪表 · 面板 · 丝印标签 · 信号灯 · 点阵读数 · 暖纸色 · 精密 · 有分量 · 克制 · 可靠。

**不是**：拟物皮革 / 复古怀旧（不做做旧）· 赛博朋克 / 霓虹 · 玻璃拟态 / 模糊 / 折射 · 紫蓝渐变 · 扁平极简到毫无质感 · 儿童玩具式的高饱和多彩。

**一句话检验**：把界面截图拿给不知道品牌的人看，他们会说“像一台设计很好的仪器”，而不是“像一个复古 App”或“像一个普通 SaaS”。

### 3.2 状态色（指示灯专用）

橙色已被“活动”占用，其余状态各有灯色。**必须**同时配文字状态词，不能只靠颜色。

| 状态 | 灯色 | 文字色（用于文字时） | 读数 | 含义 |
| --- | --- | --- | --- | --- |
| 空闲 IDLE | `#b5afa1`（灭） | `--ink-muted` | `IDLE` | 无任务 |
| 运行 RUNNING | `#ff5a1f` + 光晕 | `--signal-text` | `RUNNING` | 正在工作 |
| 等待 WAITING | `#e0a21b` | `#8a5a00` | `WAITING` | 等待人工审批 / 输入 |
| 完成 DONE | `#3a9a5b` | `#2a6f45` | `DONE` | 成功结束 |
| 故障 FAULT | `#c62828` | `#a61e1e` | `FAULT` | 失败 / 需要处理 |

### 3.3 深色主题（“夜间仪器”）

深色**不是反色**，而是把整台仪器放进暗处：面板变成深暖灰，高光变成 1px 微亮边，灯更亮但仍克制。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--surface-base` | `#191714` | 最底层 |
| `--surface-panel` | `#24211d` | 主面板 |
| `--surface-tray` | `#1e1b17` | 输入托盘 |
| `--surface-inset` | `#15130f` | 深凹槽 / 仪表条 |
| `--surface-inset-soft` | `#1b1915` | 浅凹槽 / 选中项 |
| `--surface-paper` | `#1d1a16` | 输入纸面 / 代码区 |
| `--key-top` → `--key-bottom` | `#2f2c27` → `#24211d` | 按键渐变 |
| `--ink` | `#ece7dc` | 主文字 |
| `--ink-muted` | `#a79f90` | 次要文字 |
| `--line` | `#3a352e` | 分隔线 |
| `--tick-off` | `#4a453c` | 刻度未点亮 |
| `--signal` | `#ff6a2f` | 信号橙（略提亮） |
| `--signal-text` | `#ff8a57` | 橙色文字 / 链接 |
| `--on-signal` | `#1a120c` | 信号按钮上的文字 |
| 高光边 | `rgba(255,255,255,.07)` | 替代浅色下的白色顶部高光 |
| 阴影 | `rgba(0,0,0,.5)` | 替代暖棕阴影 |

### 3.4 对比度要求与相对原型的修正

以下比值为按 WCAG 公式估算，**落地前请用工具复核**：

| 组合 | 估算对比度 | 结论 |
| --- | --- | --- |
| `--ink` on `--surface-panel` | 约 13:1 | ✅ 正文 |
| `--ink-muted (#6b655b)` on panel | 约 5.0:1 | ✅ 小字次要文字 |
| `#7a746a` on panel | 约 4.0:1 | ⚠️ **不可用于小号文字**，仅限非文字元素 |
| `--signal (#ff5a1f)` on panel（作文字） | 约 2.7:1 | ❌ **禁止作文字色** |
| 白字 on `--signal` | 约 3.1:1 | ❌ 小号按钮文字不达标（原型用了白字，需修正） |
| `--on-signal (#26231f)` on `--signal` | 约 5.0:1 | ✅ **信号按钮用深墨色文字** |
| `--signal-text (#b8360a)` on panel | 约 5.1:1 | ✅ 橙色文字 / 链接 |

**相对第一版原型的两处修正（必须）**：① 次要文字改用 `#6b655b`；② 信号按钮文字改为深墨色（或改用更深的橙 + 白字）。

### 3.5 色彩使用规则

- **必须**：状态不能只靠颜色表达，灯色要配状态词或图标。
- **应该**：图表用“墨色线 + 单个橙色高亮”，多系列时用**明度差 + 线型**（实线 / 虚线 / 点线）区分，而不是彩虹色。
- **应该**：图片与截图放进面板时，周围保留暖米色边距，不与背景硬撞。
- **必须**：主题切换时，编辑器 / Diff / 终端 / 图表一并切换（见第 10.5 节）。

## 4. 字体系统

### 4.1 三种角色

| 角色 | 用途 | 字体栈 |
| --- | --- | --- |
| **Sans（界面 / 正文）** | 标题、正文、按钮、菜单 | `system-ui, "SF Pro Text", "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`（品牌若已有指定界面字体，则替换为该字体） |
| **Mono（标签 / 元信息 / 代码）** | 丝印标签、路径、工具名、时间、数值单位、代码 | `"JetBrains Mono", ui-monospace, "Cascadia Mono", Menlo, monospace` |
| **Dot（点阵读数）** | 仪表读数：状态词、计数、大号数字 | `"Doto", "JetBrains Mono", ui-monospace, monospace`（Doto 为开源点阵字体，OFL 授权，字重 700 效果最佳） |

**桌面应用（Wails）必须把字体打包进应用（自托管子集），不要依赖在线字体。** 官网可以用自托管，也可以用在线字体服务，但都要设置完整的回退栈。

### 4.2 点阵字（Dot）使用边界——最容易滥用的地方

- **可以用于**：状态词（`RUNNING`、`IDLE`）、计数（`04/07`）、时间（`00:12`）、大号统计数字、官网的展示级大字、空状态的一个词。
- **必须**：只用于**英文大写与数字**。Doto 不含中文字形，中文会回退到系统字体，风格会断裂。所以**读数一律用英文词 / 数字**，中文放在旁边的普通标签里。
- **必须**：不用于正文、按钮文字、菜单、表单标签。
- **应该**：最小 14px（清晰度），常用 16 / 24 / 48 / 72px；一屏里点阵字块**不超过 2–3 处**。
- 字距 `+0.08em`，不做斜体，不加描边。

### 4.3 应用界面字号阶梯

| 层级 | 字号 / 行高 | 字体 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| Label | 11px / 16 | Mono 大写 | 400–700 | 丝印标签，字距 `+0.12~0.24em` |
| Caption | 12px / 18 | Sans 或 Mono | 400 | 辅助说明、元信息 |
| Control | 13px / 20 | Sans | 500 | 按钮、菜单、表单控件 |
| Body | 14px / 22 | Sans | 400 | 界面正文 |
| Chat | 15px / 26（约 1.75） | Sans | 400 | 聊天正文，长时间阅读 |
| Title | 20px / 28 | Sans | 600 | 页面 / 会话标题 |
| Readout | 16 / 24px | Dot | 700 | 仪表读数 |

### 4.4 网页字号阶梯

| 层级 | 字号（桌面 / 移动） | 字体 | 字重 | 字距 |
| --- | --- | --- | --- | --- |
| Display（点阵大字） | 72 / 44px | Dot | 700 | `+0.04em` |
| H1 | 64 / 38px，行高 1.05 | Sans | 600 | `-0.03em` |
| H2 | 40 / 28px，行高 1.15 | Sans | 600 | `-0.02em` |
| H3 | 24 / 20px | Sans | 600 | `-0.01em` |
| Lead | 20 / 17px，行高 1.6 | Sans | 400 | 0 |
| Body | 16px，行高 1.7 | Sans | 400 | 0 |
| Label | 12px | Mono 大写 | 400–700 | `+0.14em` |

### 4.5 中文排版

- 中文不加字距（最多 `+0.02em`），不使用大写与宽字距（那只属于拉丁字母标签）。
- 中英混排时，英文标签用 Mono，中文说明用 Sans，**不要把中文放进 Mono 标签**。
- 正文行高 1.7\~1.75，段落间距 0.75em 以上。

## 5. 形状、间距与栅格

### 5.1 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r-tick` | 2px | 刻度、小方块标记 |
| `--r-sm` | 4px | 标签贴、代码标签 |
| `--r-md` | 8px | 输入纸面、列表项、小按钮 |
| `--r-lg` | 10px | 按键、仪表条、用户消息 |
| `--r-panel` | 14px | 主面板、托盘 |
| `--r-hero` | 20px | 官网大面板、产品展示框 |
| `--r-pill` | 99px | 仅限：分段控件的滑块、徽章 |
| 圆形 | 50% | **仅限**指示灯 |

规则：**同一层级圆角一致；内层圆角 = 外层圆角 − 内边距**（嵌套时视觉更顺）。

### 5.2 间距（4px 基准）

`4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 · 64 · 96`

- 机身外边距 12px，面板之间 12px（“机身缝隙”）。
- 面板内边距：紧凑 12 / 标准 16–22 / 宽松 32。
- 网页区块垂直间距：桌面 96–128，移动 64。

### 5.3 栅格

- **应用**：以面板为单位的“机身布局”，面板按功能划分（导航 / 主内容 / 辅助）。
- **网页**：12 列，最大内容宽度 1200px，列间距 24px；展示区可撑到 1320px。
- **基线**：8px；控件高度取 28 / 32 / 36（触屏 ≥ 44）。

### 5.4 分隔与刻度

- 常规分隔：1px `--line`。
- **刻度尺分隔（招牌细节）**：用于章节标题下方或面板边缘：

  ```css
  .ruler{height:8px;background:repeating-linear-gradient(90deg,var(--line) 0 1px,transparent 1px 8px)}
  ```

  长刻度每 5 格加高一次即可（可用第二层渐变叠加）。**每个页面最多 1–2 处**，不要铺满。

## 6. 材质与光影（这套风格的核心）

### 6.1 光源约定

**光从正上方略偏左照下**，全站一致：

- 凸起元素：**顶部 1px 高光 + 底部 2–3px 实边 + 柔和外阴影**。
- 凹陷元素：**内阴影自上而下**，顶部深、底部浅。
- **必须**：阴影用暖色（`rgba(60,50,30,α)`）；深色主题用 `rgba(0,0,0,.5)`。**不使用模糊、玻璃、彩色发光**（指示灯的光晕除外）。

### 6.2 立体层级（最多三层）

| 层级 | 用途 | 配方（浅色） |
| --- | --- | --- |
| **L0 平** | 内容文字底 | 无阴影 |
| **L1 面板** | 侧栏、内容区、卡片 | `box-shadow: 0 1px 0 #fff inset, 0 0 0 1px rgba(0,0,0,.08), 0 8px 20px rgba(60,50,30,.10);` |
| **L2 按键** | 可按元素 | `background: linear-gradient(#faf8f2,#e9e5da); box-shadow: 0 1px 0 #fff inset, 0 2px 0 rgba(0,0,0,.16), 0 3px 6px rgba(0,0,0,.10);` |
| **信号按键** | 主操作 | `background: linear-gradient(#ff7a45,#ff5a1f); box-shadow: 0 1px 0 rgba(255,255,255,.5) inset, 0 3px 0 #c93d09, 0 6px 10px rgba(0,0,0,.2);` |

### 6.3 凹陷配方

| 用途 | 配方 |
| --- | --- |
| 仪表条 / 读数区（深） | `background:var(--surface-inset); box-shadow: inset 0 2px 5px rgba(0,0,0,.20);` |
| 输入托盘 | `background:var(--surface-tray); box-shadow: inset 0 2px 5px rgba(0,0,0,.14);` |
| 选中列表项 / 用户消息 | `background:var(--surface-inset-soft); box-shadow: inset 0 2px 4px rgba(0,0,0,.22);`（用户消息为 `.16`） |

### 6.4 指示灯

```css
.lamp{width:12px;height:12px;border-radius:50%;background:var(--signal);
  box-shadow:0 0 10px var(--signal), inset 0 -2px 3px rgba(0,0,0,.25)}
.lamp[data-state="idle"]{background:var(--tick-off);box-shadow:inset 0 -2px 3px rgba(0,0,0,.25)}
```

- 小尺寸列表内的灯：8px，光晕 `0 0 8px`。
- 灯默认**静态**，不闪烁。仅在“需要注意”的短时场景（如刚进入 WAITING 的几秒）可做一次淡入，并**必须**遵守减少动态设置。

### 6.5 按键状态

| 状态 | 表现 |
| --- | --- |
| 默认 | 见 6.2 |
| 悬停 | 上移 1px，渐变提亮约 3%（不变色相） |
| 按下 | 下移 2px，底部实边缩为 1px，外阴影收窄（“按进去”） |
| 焦点（键盘） | 外圈 `outline: 2px solid var(--ink); outline-offset: 2px`（**必须可见，不能去掉**） |
| 禁用 | 去掉阴影与渐变，变为平面，文字 `--ink-faint`，`cursor:not-allowed` |
| 加载 | 按钮文字替换为点阵读数或刻度步进（**不做无限转圈动画**） |

### 6.6 用得对与用得错

✅ 面板凸起 → 内部是凹陷的输入托盘 → 里面是平的纸面：**由外到内逐级“沉入”**。 ❌ 每张卡片都凸起、每个标签都凹陷：会变成一堆浮雕，失去层级。 ❌ 在凸起按键内再放凸起按键。

## 7. 图标、Logo 与图形

### 7.1 图标

- **线性图标**，线宽 1.75px，圆角端点与拐角，16 / 20px 两档。桌面应用统一 **Lucide**；官网若无 Lucide 也保持同风格（等线宽、无填充、无阴影）。
- **同一含义固定一个图标**，不使用 Emoji 代替图标。
- 状态图标**配合指示灯**使用：灯表达“有没有在动”，图标表达“是什么”。

### 7.2 Logo

- 应用内**使用现有 EDITH Logo，不要重画**。
- 无 Logo 场景的文字标识：Mono 粗体大写、字距 `+0.24em`（例如 `E D I T H` 的稀疏感）。
- Logo 安全边距 ≥ Logo 高度的 1/2；最小尺寸 16px。
- 应用图标建议：圆角方形底 `#f2efe7`，居中放 Logo，右上角一个 `--signal` 小圆灯作为“唯一橙点”（可以）。

### 7.3 插画与图示

- **不做卡通插画**。需要图示时，用**技术图纸语言**：细线框、尺寸标注线、编号引线（`FIG. 01`、`①②③`）、Mono 小字说明。
- 产品截图**放进“面板框”**（L1 面板 + 1px 内描边），像装在机身里的显示屏。
- 摄影（如有）：暖色柔光、顶部光源、浅景深、背景为米色纸面或哑光塑料，**不用冷蓝调**。

### 7.4 数据可视化

- 墨色线条为主，**一个橙色高亮**强调重点。
- 网格用刻度式短线，不用满格实线。
- 进度用**分格刻度条**（`▮▮▮▮▯▯▯`），不用平滑渐变进度条。
- 数字读数用 Dot 字体，单位用 Mono 小字。

## 8. 动效与声音

### 8.1 原则：机械感，不是弹性感

- 反馈像**机械动作**：干脆、短促、有阻尼，**没有弹簧过冲、没有果冻回弹**。
- 数值变化用\*\*步进（`steps()`）\*\*或直接切换，不用淡入淡出的模糊过渡。

### 8.2 时长与曲线

| 动作 | 时长 | 曲线 |
| --- | --- | --- |
| 按键按下 / 弹起 | 80ms | `ease-out` |
| 悬停 | 120ms | `ease-out` |
| 面板展开 / 抽屉 | 200ms | `cubic-bezier(.2,.8,.2,1)` |
| 刻度点亮 | 瞬间（或 `steps(1)`） | — |
| 读数翻页 | 直接替换，可选 60ms 位移 | `steps(2)` |

### 8.3 必须遵守

- **必须**：支持 `prefers-reduced-motion`，减弱时去掉位移与过渡，仅保留状态变化。
- **必须**：长时间阅读区域（聊天、文档、代码）**无持续动画**。
- **必须**：状态动效只反映真实状态，不制造“正在完成”的假象。
- 官网：**不做视差滚动、不做自动播放的循环动画、不做鼠标跟随光效**；滚动入场最多一次性淡入位移 8px。

### 8.4 声音 / 触感（可选）

可以为按键提供极轻的“咔嗒”音，但**默认关闭**、在设置中可开，并遵守系统静音。桌面端触控板 / 手机的触感反馈同理，默认关闭或跟随系统。

## 9. 组件库

> 下列均为**通用组件规格**；具体载体只取所需。CSS 均基于第 12 章的 token。

### 9.1 仪表条（Instrument Strip）——招牌组件

一条凹陷的读数带，从左到右：**指示灯 · 状态词（Dot） · 分格刻度 · 计数（Dot） · 时间**。

```css
.strip{display:flex;align-items:center;gap:14px;padding:10px 16px;border-radius:var(--r-lg);
  background:var(--surface-inset);box-shadow:inset 0 2px 5px rgba(0,0,0,.20);
  font:700 16px var(--font-dot);letter-spacing:.08em}
.ticks{display:flex;gap:4px}
.ticks b{width:6px;height:16px;border-radius:1px;background:var(--tick-off)}
.ticks b.on{background:var(--signal)}
```

- 刻度数量 = 总步数（≤ 12，超过则改为数字读数）。
- **应该**为读屏用户提供文本等价：`role="status"` + `aria-label="运行中，第 4 步，共 7 步"`。
- **窄屏**：隐藏刻度，仅保留灯 + 状态词 + 计数。

### 9.2 按钮

| 类型 | 外观 | 用途 |
| --- | --- | --- |
| **信号按钮** | 橙色渐变 + 底边厚度 + 深墨色文字 | 每个视图**至多一个**主操作 |
| **按键（次要）** | 米色渐变凸起 | 常规操作 |
| **文字按钮** | 无背景，悬停下加 1px 下划线 | 低优先级、链接式操作 |
| **图标按钮** | 32px 方形按键，`aria-label` 必填 | 工具栏 |
| **危险按钮** | 按键外观 + `FAULT` 红色左标记，二次确认 | 删除 / 不可逆 |

尺寸：28 / 32 / 36（触屏 ≥ 44）。左右内边距 12–18px。文案：Sans 13px / 500，主按钮可用 Mono 大写 `+0.12em`（仅英文短词）。

### 9.3 输入

- **托盘 + 纸面**结构：外层凹陷托盘，内层 `--surface-paper` 纸面，圆角 8px，内边距 10–12px。
- 聚焦：纸面外圈 2px `--ink` 描边（不使用橙色作焦点色，避免与“活动”混淆）。
- 错误：纸面左侧 3px `--fault` 竖条 + 下方错误文字（配图标）。
- 多行输入自适应高度，最大高度后内部滚动。
- 行内标签（如命令 / Skill 标签）：`--signal-tint` 底，Mono 12px，圆角 4px。

### 9.4 选择类

| 组件 | 规格 |
| --- | --- |
| **开关（Switch）** | 36×20 凹陷轨道；滑块为凸起小按键；开启时轨道内侧显示橙色灯条 |
| **分段控件** | 凹陷轨道，选中项为凸起滑块；键盘左右键切换 |
| **单选 / 复选** | 凹陷方孔（复选，圆角 4）/ 圆孔（单选），选中时内含橙色实心方块 / 圆点 |
| **下拉 / 菜单** | L1 面板浮层，圆角 12，选中项凹陷 + 左侧 8px 小灯 |
| **滑杆（Fader）** | 凹陷凹槽 + 刻度 + 凸起滑块；数值用 Dot 读数 |

### 9.5 导航与列表

- **侧栏列表项**：默认平；**悬停**显示 `--surface-inset-soft` 浅底；**选中**为凹陷 + 左侧 8px 橙色小灯；文字加粗 600。
- **标签页（Tabs）**：分段控件式凹陷轨道；选中项为凸起或墨色实心药丸（二选一，全站一致）。
- **面包屑 / 路径**：Mono 12px，分隔符用 `/`。
- **章节标题（标签铭牌）**：`■ SECTION NAME` —— 8px 圆角 2px 的墨色方块 + Mono 大写 + `+0.14em` 字距。

### 9.6 信息与反馈

- **徽章 / 标签贴**：Mono 11px 大写，`--surface-inset-soft` 底，圆角 4px，像标签机打印的胶带。
- **提示条（Toast）**：横向“标签胶带”，左侧状态灯 + 文本，8 秒后自动消失（可暂停），必须有可键盘关闭的按钮。
- **工具提示（Tooltip）**：深墨色小铭牌 `#26231f`，文字 `#f2efe7`，Mono 或 Sans 12px，延迟 400ms，**触屏与键盘焦点也能触发**。
- **对话框**：L1 面板居中，圆角 14，背后遮罩为半透明暖黑 `rgba(38,35,31,.45)`，**不使用背景模糊**。
- **进度**：分格刻度条 + 数字读数；不确定进度用“刻度步进扫描”并遵守减少动态。
- **空状态**：Dot 字体的一个英文词（`EMPTY` / `READY`）+ 一行中文说明 + 一个信号按钮。
- **骨架屏**：灰米色平块，不做流光。

### 9.7 显示屏（代码 / 终端 / Diff）

- 编辑器 / 代码：`--surface-paper` 纸面，位于凹陷边框内。
- **终端可以是“暗屏 LCD”**：深色底 `#191714`，作为凹陷窗口嵌在浅色界面里，是全局最强对比区域（见 10.5 配色）。
- Diff：新增 `rgba(46,160,67,.18)` 行底，删除 `rgba(229,72,77,.18)` 行底，行号 Mono 灰色。

### 9.8 表格与数据

- 表头：Mono 大写 11px，下方 1px `--line`；数字列右对齐，Mono；行间距 40px；隔行不加底色，悬停行加 `--surface-inset-soft`。
- 官网“规格表”：两列，左侧标签（Mono 大写），右侧值，行间用细线，像产品规格页。

- 共用页面里**不判断操作系统**；字体打包、窗口圆角等平台差异由接入层处理。

### 11.2 区块规范

- **节奏**：区块以“模块”方式堆叠在机身背景上，面板圆角 20，模块间距 24–48；区块编号 `01 — 07` 用 Mono 标签，帮助建立“规格手册”的秩序感。

- **规格铭牌**：Dot 大数字（48–72px）+ Mono 标签（如 `TASKS / DAY`）+ 一句 Sans 说明。用真实且可核实的数据；**没有真实数据时不要编造数字**，改用能力描述。
- **规格对比表**：见 9.8；亮点单元格用一个橙色小灯，而非整格染色。
- **定价卡片**：顶部型号标签（Mono）、价格用 Dot 或大号 Sans、特性列表用小灯 / ✓；推荐档位使用信号按钮，其余为按键。
- **FAQ**：每项左侧一个小开关状态（凹陷方孔，展开时点亮）；展开内容平面文字。
- **导航**：顶栏为一条 L2 凸起长条（吸顶时保持），当前页为凹陷项；移动端折叠为汉堡按键 + 全屏面板。

| --- | --- |
| ≥ 1200 | 12 列，Hero 左文右图可选 |
| 768–1199 | 8 列，展示面板占满宽，区块内两列变一列 |
| \< 768 | 单列，H1 38px，仪表条隐藏刻度，间距缩至 64，导航折叠 |

### 11.4 性能与工程

- 立体感**纯 CSS**（渐变 + 阴影），不需要图片资源；首屏只需要 Sans + Dot 两个字体文件（**子集化**，仅含用到的字符）。
- 图片使用现代格式与 `loading="lazy"`，展示图预留宽高避免抖动。
- **必须**：语义化 HTML、可键盘操作的手风琴与菜单、跳转主内容链接。
- 明暗主题跟随系统，同时提供手动切换。

### 11.5 官网文案语气

标题短而具体（“让 Agent 的每一步都看得见”），避免夸张形容词；能力描述用**名词 + 数字 + 动词**；按钮文案用动词（“下载”“阅读文档”），不用“了解更多”一类空话。

## 12. 落地：Token 与代码

### 12.1 CSS 变量（浅色 + 深色）


## 13. 其他载体速查

| 载体 | 要点 |
| --- | --- |
| **移动端 App** | 底部“摇杆式”分段导航（凹陷轨道 + 凸起选中块）；触点 ≥ 44；仪表条常驻顶部；面板圆角 14，去掉外边距 |
| **文档站 / 博客** | 正文用 Sans 16px / 1.7，宽度 ≤ 720；侧边目录像面板目录铭牌；代码块=凹陷暗屏或纸面；标题下用刻度尺分隔 |
| **仪表盘 / 后台** | 顶部一排“读数块”（Dot 大数字 + Mono 标签）；图表墨线 + 单橙高亮；表格用 9.8；筛选器用分段控件与开关 |
| **幻灯片（16:9）** | 米色背景 + 一个面板框内放主内容；页码 / 章节用 Dot 读数（如 `03/12`）；每页最多一个橙色元素；正文 ≥ 24px |
| **海报 / 印刷** | 信号橙作专色；Mono 小字做角标与参数栏；网格严谨、留白大；避免渐变与阴影，用线条与色块表达“凸起感” |
| **邮件 / 社交图** | 米色底，顶部标签铭牌，一个大标题，一个信号按钮；阴影用实色偏移代替（兼容性） |
| **CLI / TUI** | 底色 `#191714`，主文 `#ece7dc`，强调 `#ff6a2f`，状态灯用 `●`，进度用 `▮▯` |
| **启动页 / 加载** | 中央一个 Dot 词（`BOOT` / `READY`）+ 刻度逐格点亮；耗时 \< 1s 则不显示 |
| **Favicon** | 16 / 32px 方形，米色底 + 单个橙点，简单到一眼可识别 |

## 14. 无障碍清单

- 文字对比度 ≥ 4.5:1（大字 ≥ 3:1）；按第 3.4 节的规则选色。
- 所有交互元素有**可见键盘焦点**（2px 墨色外圈）；图标按钮有名称与提示。
- 状态不只靠颜色：灯 + 状态词 / 图标。
- 触屏点击区 ≥ 44px（桌面紧凑密度可 ≥ 28，但需要提供舒适密度）。
- 支持 `prefers-reduced-motion`、`prefers-color-scheme`；高对比 / 强制色彩模式下，凸起 / 凹陷靠**边框**表达（`@media (forced-colors:active){ .btn,.panel{border:1px solid CanvasText} }`）。
- 点阵字仅作视觉读数，**关键信息需有文本等价**。
- 内容增长时不破版：长名称省略并提供完整提示，长代码横向滚动，表格在容器内滚动。

## 15. 反面清单（做了就不对）

| ❌ 不要 | ✅ 应该 |
| --- | --- |
| 每个元素都凸起 | 只有可操作元素凸起，内容平或凹陷 |
| 橙色大面积铺底 / 橙色正文 | 橙色只做灯、刻度、主按钮、选中标记，占比 ≤ 5% |
| 点阵字用于正文、中文、按钮 | 点阵字只做英文状态词与数字，一屏 ≤ 2–3 处 |
| 假的进度动画、循环闪烁的灯 | 灯与刻度只反映真实状态；默认静态 |
| 纯黑阴影、冷灰背景 | 暖色阴影、暖米色中性色 |
| 玻璃、模糊、紫蓝渐变、霓虹 | 平实的渐变（仅按键）与阴影 |
| 拟物：皮革、金属拉丝、螺丝、旋钮堆叠 | 只保留质感与秩序 |
| 白字压在橙色小按钮上 | 深墨色文字，或更深的橙 + 白字 |
| 用灯色单独表达状态 | 灯 + 文字状态词 |
| 官网视差、自动循环动画 | 静态快照，一次性入场 |

## 16. 交付前自检清单（20 项）

1. 页面里只有**一个信号橙**，且占比 ≤ 5%。
2. 每个视图**至多一个**信号按钮。
3. 立体层级不超过三层，没有“凸起叠凸起”。
4. 所有阴影方向一致（正上偏左），且是暖色。
5. 点阵字只出现在英文词 / 数字，且一屏 ≤ 3 处。
6. 灯与刻度对应真实状态，没有假动画。
7. 文字对比度全部达标（特别检查次要文字与橙色相关的文字）。
8. 每个交互元素都有可见焦点与名称。
9. 状态都有“灯 + 文字”。
10. 明暗主题都检查过（不是简单反色）。
11. 长内容、窄屏、触屏都能用。
12. 支持减少动态，长时间阅读区无持续动画。
13. 图标同一含义固定一个，未使用 Emoji。
14. 使用现有 Logo，没有重画。
15. 同类组件全部来自公共组件，无零散覆盖样式。
16. 圆角只取自档位表，嵌套圆角协调。
17. 间距只取自 4px 阶梯。
18. 标题 / 标签 / 读数三种字体角色没有混用。
19. 官网：无视差、无自动循环、首屏无大图依赖。
20. 桌面：三端 WebView 都验证过，字体已打包，`color-mix()` 有回退。
