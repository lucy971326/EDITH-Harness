# Settings / Credentials V1 —— 拍板用

配置和钥匙从 `compose.Config` 里拆出去。Commands 已经有报名表；这次是抽屉柜和保险柜。

## 它是什么

现在所有东西挤在一张中心表里。`compose` 认识 DeepSeek 的每一个字段，钥匙和网址走同一条路。

```text
现在
  compose.Config
    plugins: 谁上场
    providers.deepseek.api_key     ← 钥匙
    providers.deepseek.base_url    ← 普通配置
```

以后分成三件事：

```text
谁上场     config.yaml 的 plugins:     compose 只看名单
普通配置   每个插件自己的抽屉           settings
钥匙       保险柜，只有适配器能领       credentials
```

**抽屉名**（竞品叫 namespace）= 柜子上贴的名字。`deepseek` 只能打开 `deepseek` 抽屉，拿不到别人的。

## 文件就两份

`~/.harness/config.yaml` —— 名单 + 普通配置：

```yaml
version: 2

plugins:
  llm_adapters:
    - deepseek
  tool_plugins:
    - files
  ui: web

settings:
  deepseek:
    base_url: https://api.deepseek.com
```

`~/.harness/credentials.yaml` —— 只放钥匙（权限 600）：

```yaml
deepseek:
  api_key: sk-xxxx
```

插拔还是改 `plugins:`。本项目静态编译：新插件仍要写进 Go、编进二进制。YAML 名单只决定这次装哪些已经编进来的零件。

## 三层（还是报名表那套）

```text
config 插件           提供 settings + credentials
deepseek 等能力插件   登记自己的抽屉，领取钥匙，填充 llm 的 Adapter 插槽
compose               只按 plugins: 名单组装，不认识 api_key / base_url
```

Web 现在 **不读钥匙**。设置页以后再做；V1 的第一个消费方是 DeepSeek 自己。

## 铁律

1. 钥匙不进 `settings`、不进 UI、不进日志、不进账本。普通配置接口读不到明文。
2. `compose` 只认 `plugins:` 名单，不认每个插件的字段。
3. 插件只读自己那一格。没有的键用它自己的默认值。
4. 空钥匙 = 没有。说「缺钥匙」，绝不把密钥片段打出来。
5. settings 不是业务状态。上次用哪个模型还是项目自己记，不进抽屉。
6. 登记抽屉、登记凭据需求，都返回 `unregister`。

## 抄竞品什么，不抄什么

抄：配置和钥匙分开；配置里不写密钥正文；插件自己声明自己要什么；中心组装者不认识字段。

不抄：

- 热重载、文件监视、改完立刻生效（我们静态编译，改配置重启）
- schema 引擎、自动生成设置表单
- 默认值 / 组合层 / 用户层 三层覆盖
- 环境变量、`.env`、项目 `.env` 四层抢钥匙
- 把引用做成 `DEEPSEEK_API_KEY` 这种环境变量名（我们抽屉名就是 `deepseek`）
- OAuth / 授权向导
- 每次模型请求重新领钥匙（V1 启动时领一次）

## V1 做什么

```text
settings 服务
  Register 抽屉（名字 + 默认值 + 校验）
  Get / Set 自己那一格
  落在 config.yaml 的 settings: 下

credentials 服务
  按抽屉名存取钥匙
  Resolve 只把明文交给调用方
  落在 credentials.yaml
  给 UI 的询问只回答「有没有」，不给值

compose
  删掉 providers.deepseek 结构体
  DeepSeek 插件 Start 时自己读抽屉、领钥匙

第一个真实填抽屉的人：deepseek
```

V1 不做：设置页、热更新、环境变量层、OAuth、通用 schema 表单。

## 请拍这三板

1. **就两份文件。** 普通配置进 `config.yaml` 的 `settings:`，钥匙进 `credentials.yaml`。不拆成每个插件一个文件。
2. **V1 就把 DeepSeek 从中心表拆走。** 这是第一个真实抽屉，不是再发明一个假插件。
3. **V1 没有设置页。** 人暂时手改 YAML；网页碰钥匙是以后的事。
