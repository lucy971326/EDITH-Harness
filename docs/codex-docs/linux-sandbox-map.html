bwrap · Linux 沙箱启动工具

它先搭好环境，再启动 Agent 命令。

具体例子

Codex 告诉 bwrap：系统文件只读、项目目录可写、网络隔离。bwrap 调用 Linux 内核完成这些设置，然后运行命令。项目文件没有被复制。

如果拿掉它：仍可自己写代码调用 namespace 和挂载接口，或使用别的工具；内核能力本身还在。

记住这个形状

bwrap 是调用内核能力的工具；namespace、cgroup、seccomp 是内核机制。 bwrap 擅长搭 namespace 和挂载，也能加载现成 seccomp 过滤器；cgroup 的 CPU、内存配额需要另外设置。挂进去的可写项目目录仍是宿主机的真实文件。
