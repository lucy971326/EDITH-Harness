# surface/web

【它是什么】Web 表面插件：公共页面壳、HTTP 服务、产品与设置登记处。

【使用能力】不 Resolve 其他服务。

【提供能力】注册服务 `web`：启动 HTTP Server，提供产品登记、路由登记和公共 `settings.section` 登记处；同时拥有 Token、公共 UI 规则和受控图标。

【填充插槽】不填；它提供三个登记口：产品、路由、`settings.section`。

【谁在用】`chat` 与 `web/demo` 登记产品和路由；`settings/demo` 登记设置栏目；浏览器通过它访问所有 Web 页面。

【不做】不认识 Chat、Runner、Session 或任何具体产品业务。

---

### 一句话心智

`surface/web` 自身不实现任何具体产品，纯粹是一个只管外壳与挂载的**公共舞台**：
1. **搭骨架**：画出整站通用的左侧大边栏、主题外观（亮/暗）与静态资源。
2. **开网络**：启动底层的 HTTP 服务器，监听指定端口。
3. **给接口**：提供产品、路由、设置三个登记处，让 Chat、Demo 等具体产品自己报到挂载。
